## 📖 About This Project

**TaskFlow Pro** is a fully interactive, single-page task management application built from the ground up using a unique blend of **human algorithmic design** and **AI-powered development**. 

This project represents a milestone in my journey as a software engineer, combining multiple layers of learning and execution:

### 🧠 What Makes This Project Special

#### 1. **Algorithmic Thinking & Problem Solving**
Every feature—from task CRUD operations to drag-and-drop reordering, command palette navigation, and reactive state management—was architected with clean, modular, and efficient algorithms. I designed the data flow, state transitions, and event handling logic to ensure a smooth, bug-free user experience.

#### 2. **AI-Assisted Development & Prompt Engineering**
This project was built **with** AI, not *by* AI. I leveraged advanced **prompt engineering techniques** learned from a professional online course to:
- Generate high-quality, production-ready code snippets
- Debug complex issues through structured, context-aware prompts
- Optimize code structure and refactor legacy logic
- Design scalable architecture patterns (IIFE wrappers, state management, storage layers)

This process transformed AI from a "code generator" into a **pair programmer** that amplified my productivity without compromising code quality or my understanding of the underlying systems.

#### 3. **Professional Git & GitHub Workflow**
I applied industry-standard version control practices learned in the same online program:
- **Conventional Commits** (`feat:`, `fix:`, `refactor:`, `perf:`) for clear, maintainable history
- **Atomic commits** that isolate features (constants, i18n, storage, state, UI, etc.)
- **Descriptive commit messages** with body context for future reference
- Clean branch management and organized repository structure

This discipline ensures the project is not only functional but also **collaboration-ready** and **auditable**—a skill that sets me apart as a professional developer.

## 🛠️ Tech Stack & Architecture

### Core Technologies
- **Vanilla JavaScript (ES6+)** – No frameworks, pure performance
- **LocalStorage API** – Persistent data layer
- **Custom State Management** – Reactive state with selectors
- **IIFE Pattern** – Encapsulated, pollution-free modules

### Key Modules
| Module | Description |
|--------|-------------|
| **Constants & i18n** | Centralized configuration & multilingual support (EN/FA) |
| **Storage Layer** | Persistent data with TTL and JSON serialization |
| **State & Selectors** | Reactive state with memoized derived data |
| **Toast Notifications** | User feedback system (success, error, warning, info) |
| **Rendering Engine** | DOM manipulation with event delegation |
| **Task Operations** | Full CRUD with status, priority, and due dates |
| **Task Modal** | Create/Edit forms with validation |
| **Command Palette** | Keyboard-first navigation (Ctrl+K) |
| **Drag & Drop** | Intuitive task reordering |
| **Settings & Routing** | User preferences and view navigation |
| **Event Bus** | Decoupled module communication |
| **Bootstrap** | Clean app initialization sequence |
